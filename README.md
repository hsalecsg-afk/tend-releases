# Tend

Tend는 업무 후속 관리를 위한 데스크톱 앱입니다.

오늘 해야 할 일, 나중에 확인할 일, 이어서 처리해야 할 업무를 기업, 그룹, 프로젝트 단위로 정리할 수 있습니다.

## 다운로드

최신 버전은 [GitHub Releases](https://github.com/hsalecsg-afk/tend-releases/releases)에서 다운로드할 수 있습니다.

| 운영체제 | 아키텍처 | 설치 파일 |
| --- | --- | --- |
| macOS | Apple Silicon | `Tend_0.8.0_aarch64.dmg` |
| macOS | Intel | `Tend_0.8.0_x64.dmg` |
| Windows | x64 | `Tend_0.8.0_x64-setup.exe` |

현재 최신 버전은 [Tend v0.8.0](https://github.com/hsalecsg-afk/tend-releases/releases/tag/v0.8.0)입니다.

## 설치 방법

### macOS

1. 사용하는 Mac에 맞는 `.dmg` 파일을 다운로드합니다.
2. 파일을 열고 Tend를 Applications 폴더로 이동합니다.
3. 처음 실행할 때 보안 경고가 표시되면 시스템 설정의 개인정보 보호 및 보안 메뉴에서 실행을 허용합니다.

### Windows

1. `Tend_0.8.0_x64-setup.exe`를 다운로드합니다.
2. 설치 파일을 실행합니다.
3. Windows SmartScreen 경고가 표시되면 `추가 정보`를 선택한 뒤 `실행`을 클릭합니다.

## 자동 업데이트

Tend는 GitHub Releases를 통해 자동 업데이트를 지원합니다.

일반 사용자는 운영체제에 맞는 `.dmg` 또는 `.exe` 설치 파일을 다운로드하면 됩니다.
